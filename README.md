# EchoSphere — XR Gallery

WebXR gallery for IPMD, Inc. Built with Three.js + Vite + TypeScript. Viewable in any browser, fully immersive in VR headsets.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:5173 — drag to look, scroll to zoom, click pieces for floating info cards. ENTER VR button appears on WebXR-capable devices.

## Build

```bash
npm run build
```

## Controls

- **Desktop** — drag to look · scroll to zoom · click a piece → info card floats in 3D space.
- **VR (headset)** — controllers get a laser aim; pull the trigger on a piece for its info card.
- ENTER VR only appears when the device supports WebXR.

## Adding content

Everything is data-driven from `src/data/artworks.json` — no code changes.

### Image piece (2D)

1. Drop the image in `public/artwork/` (e.g. `my-piece.jpg`)
2. Add a config entry:

```json
{
  "id": "my-piece",
  "title": "MY PIECE",
  "artist": "Artist Name",
  "description": "A sentence about the piece.",
  "type": "artwork",
  "image": "/artwork/my-piece.jpg",
  "x": 7.2
}
```

### 3D model (sculpture)

1. Drop a `.glb` in `public/artwork/` (e.g. `my-sculpture.glb`)
2. Add:

```json
{
  "id": "my-sculpture",
  "title": "MY SCULPTURE",
  "artist": "Artist Name",
  "description": "Loaded from a GLB file.",
  "type": "sculpture",
  "model": "/artwork/my-sculpture.glb",
  "x": -8,
  "scale": 1.2
}
```

- `x` — position along the room: back-wall pieces use `x` (spans -9..9), side-wall pieces use `z` (-9..9).
- Wall pieces: `"wall": "back" | "left" | "right"` (default `back`).
- Artwork without an `image` renders a procedural gradient (uses `colors` as HSL hues).
- Sculptures sit on a plinth at floor level; `x` moves them; `scale` sizes them.
- The example sculpture `core.glb` is generated by `node scripts/generate-assets.mjs`.
